# HANABI

基于 Three.js / WebGL 的沉浸式三维烟花模拟器。包含真实透视摄影机、三维粒子物理、动态湖面、地形与城市、Bloom 后处理、体积烟雾、现场录音和桌面/移动端自适应。

场景提供长冈、大曲、隅田川和诹访湖四种日本代表性花火大会演出模式。

## 本地运行

```bash
npm install
npm run dev
```

生产构建使用 `npm run build`，产物位于 `dist/`。
