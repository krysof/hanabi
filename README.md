# HANABI

一个无需构建步骤、可直接运行的沉浸式烟花模拟器。包含多种烟花、粒子物理、水面倒影、程序化音效、自动演出以及桌面/移动端自适应。

场景提供长冈、大曲、隅田川和诹访湖四种日本代表性花火大会演出模式。

## 本地运行

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。
